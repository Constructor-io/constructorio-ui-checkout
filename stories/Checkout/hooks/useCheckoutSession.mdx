# useCheckoutSession

A React hook that manages the checkout lifecycle: session resolution, open/close state, payment completion, and fulfillment verification. Used internally by `CioCheckout` and exported for building custom checkout UIs.

```ts
import { useCheckoutSession } from '@constructor-io/constructorio-ui-checkout';
```

## Usage

```tsx
import { useCheckoutSession } from '@constructor-io/constructorio-ui-checkout';

function CustomCheckout() {
  const {
    isOpen,
    isLoading,
    session,
    error,
    fulfillmentStatus,
    fulfillmentResult,
    openCheckout,
    closeCheckout,
    handleComplete,
    retryFulfillment,
    reset,
  } = useCheckoutSession(
    {
      session: async () => {
        const res = await fetch('/api/checkout-session', { method: 'POST' });
        return res.json();
      },
      items: [{ name: 'Widget', amount: 29.99, quantity: 1 }],
    },
    {
      onComplete: (event) => console.log('Paid:', event.sessionId),
      onError: (err) => console.error(err),
      onFulfill: async (event) => {
        const res = await fetch(`/api/verify/${event.sessionId}`);
        return res.json();
      },
    }
  );

  if (isFulfilling) {
    return <p>Status: {fulfillmentStatus}</p>;
  }

  return (
    <div>
      <button onClick={openCheckout} disabled={isLoading}>
        {isLoading ? 'Loading...' : 'Checkout'}
      </button>
      {error && <p className="error">{error.message}</p>}
      {isOpen && session && (
        // Render your own Stripe provider using session.clientSecret
        // and session.publishableKey, then call handleComplete() on success
        <YourStripeForm session={session} onSuccess={handleComplete} />
      )}
    </div>
  );
}
```

## Lifecycle Flow

```
openCheckout() → resolves session → isOpen=true
                                      ↓
                          Payment completes in Stripe
                                      ↓
                        handleComplete() → onComplete fires
                                      ↓
                  ┌─── onFulfill provided? ───┐
                  │ yes                       │ no
                  ↓                           ↓
        fulfillmentStatus='pending'     UI closes, done
                  ↓
          onFulfill() resolves
                  ↓
        ┌── success? ──┐
        │ yes          │ no
        ↓              ↓
    'fulfilled'     'failed'
                       ↓
              retryFulfillment() → re-runs onFulfill
```

## When to Use

Use `useCheckoutSession` directly when you need:

- A fully custom checkout layout that doesn't use the built-in modal/inline chrome
- Integration with an existing dialog or drawer system
- Custom loading/error states beyond what `CioCheckout` provides
- Programmatic control over the checkout flow in response to external events

For standard use cases, prefer the `<CioCheckout>` component which handles all of this internally.
